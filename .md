# Activiity Knowledge Base — Agentic RAG

Production agentic Retrieval-Augmented Generation (RAG) over a French
management/coaching corpus — the **Activiity "Fiches Protocole"** (9 learning
units: Délégation, Plaisir de travailler, Motiver, Mauvaise ambiance, Écouter
et Dialoguer, Changer les comportements, Agir sur les habitudes, Compétences
commerciales, Manager).

a ReAct router exposes a **single tool**
(`query_by_ua`), escalation to a full-corpus search is **automatic inside the
service**, and the router never writes the final answer — a dedicated
synthesis model produces it in **one pass** over the merged, post-processed
retrieval nodes.

 **Read first:** [docs/RAG_REFERENCE_GUIDE.md](docs/RAG_REFERENCE_GUIDE.md) —
architecture, prompt design and eval methodology. Also available as
[PDF](docs/RAG_REFERENCE_GUIDE.pdf), [Word](docs/RAG_REFERENCE_GUIDE.docx), and
[PowerPoint](docs/RAG_REFERENCE_GUIDE.pptx). Design rationale lives in
[docs/TECHNICAL_DESIGN.md](docs/TECHNICAL_DESIGN.md).

## How the agent works 

```
 user question
      │
      ▼
 ┌─────────────┐   observe → tool call → … → "Answer: FIN"   ┌──────────────────────┐
 │ ReAct router│────────────────────────────────────────────►│  query_by_ua(ua_ids) │
 │ (1 tool only)│    per-UA filtered search (batched, one call)│  multi-UA merge      │
 └─────────────┘                                            └──────────┬───────────┘
   │                                                                  │ 0 nodes ?
   │                                             retry ×2 (transient) ─┘
   │                                          then AUTOMATIC global fallback
   │                                                     (unfiltered corpus)
   │                                                                  │
   │  post-processing: rerank (per-UA quotas) → context compression   │
   │  de-dup → ONE synthesis pass by the synthesis model              │
   ▼
 decision:  content retrieved → synthesized answer
            nothing + plausible refusal → refusal kept verbatim
            nothing + garbage/empty    → one agent retry, then REFUSAL_FR
```

Key properties:

- **Single router tool.** `query_global` is *not* exposed to the router — it is
  an automatic escalation performed inside `_dispatch_by_ua` when filtered
  retrieval returns zero nodes (up to `RETRY_EMPTY` re-queries first). The
  router physically cannot search outside the UAs it passes.
- **One-pass synthesis.** Router-generated text is discarded; the synthesis
  model writes the answer once over the post-processed nodes (design C). This
  eliminates the paraphrase/elaboration drift the router used to introduce.
- **Robustness guards.** Garbage router output ("thought thought…", truncated
  reasoning, no tool call, no refusal) triggers **one full agent retry**; an
  out-of-scope refusal is kept verbatim only if it passes
  `_is_plausible_refusal()` (French refusal markers, short text). Empty
  synthesis always falls back to the canonical `REFUSAL_FR`.
- **Deterministic escalation, zero extra LLM round-trips.** Retry/global logic
  is code, not prompts.

## Quickstart

```bash
# 1. Install
pip install -r requirements.txt          # or use the bundled ./env venv

# 2. Provision keys (in .env — see .env.example)
OPENROUTER_API_KEY=sk-or-v1-…            # router + synthesis + judge
# OPENAI_API_KEY=sk-…                    # only if EMBED_PROVIDER=openai

#build docker
docker compose build chat
# 3. Boot Qdrant
docker compose up -d                     # or docker run qdrant/qdrant -p 6333:6333

# 4. Ingest the corpus (structure-aware chunking)
python -m activiity.ingest.cli           # --force to rebuild the collection

# 5. Run the eval (routing / refusal / retrieval / similarity / system)
python -m eval.run_eval --target agentic --tier reference \
    --out-dir reports/run_01

# 6. Add the RAGAS judge layer (gpt-4o-mini, temp 0)
python -m eval.judge_only reports/run_01 --metrics faithfulness,answer_relevancy,context_precision,context_recall,answer_correctness

# 7. Compare two runs
python -m eval.compare reports/run_00 reports/run_01

# 8. Tests
python -m pytest eval/tests -q
```

`run_eval.py` flags: `--tier reference|medium|advanced|all`, `--limit N`,
`--workers N`, `--ragas`, `--mock`, `--target naive|agentic`,
`--no-similarity --no-bertscore --no-sbert`, `--out-dir`.

## Key configuration knobs (`activiity/config.py`, all env-overridable)

| Env var | Default | Meaning |
|---|---|---|
| `LLM_MODEL` | `google/gemma-4-26b-a4b-it` | Router (ReAct agent) model |
| `HAIKU_MODEL` | `google/gemma-4-31b-it` | Synthesis model (two-LLM split) |
| `LLM_TEMPERATURE` | `0.1` | Shared router + synthesis temperature |
| `ROUTER_MAX_TOKENS` | `800` | Router only emits tool calls (design C) |
| `CONTEXT_WINDOW` | `128000` | Fixes llama-index's 3900-token wrapper default |
| `AGENT_MAX_ITER` | `4` | ReAct loop cap (a cap, not a retry) |
| `RETRY_EMPTY` | `2` | Re-queries of `query_by_ua` on zero nodes → 3 total, then global |
| `USE_RERANKER` | `1` | Reranker on (`cohere/rerank-4-pro`) |
| `RERANK_TOP_K` / `RERANK_KEEP` | `10` / `5` | Candidates/kept **per UA** (never a global top-N) |
| `TOP_K_PER_UA` / `TOP_K_GLOBAL` | `8` / `8` | Raw retrieval depth |
| `USE_STRUCTURE_SPLITTER` | `1` | Fiche-Protocole marker chunking |
| `USE_HAIKU_SYNTH` | `1` | Two-LLM split on/off |
| `EMBED_PROVIDER` / `ST_EMBED_MODEL` | `sentence_transformers` / granite-311m | Local embeddings, no network at query time |
| `ACTIVIITY_VERBOSE` | `0` | `[agentic]` debug logs (routing, nodes, fallback) |

Worst-case retrieval cost per question: up to **8 searches** (3 filtered
attempts + 1 global fallback + 1 garbage-triggered full agent rerun with its
own escalation). Release thresholds and judge config live in `eval/config.py`.

## Evaluation program

`eval/` drives any RAG (naive or agentic) over the golden set and reports:

- **Classification** — UA routing accuracy / precision / recall / F1 (macro +
  per-class), OOS class.
- **Refusal** — precision / recall of the refusal behavior (`REFUSAL_PATTERNS`
  regex in `eval/config.py`, aligned with the `REFUSAL_FR` prompt).
- **Retrieval** — Precision@k, Recall@k, MRR, nDCG@k, citation recall.
- **Similarity** — exact-match, token-F1, ROUGE-L, SBERT cosine, BERTScore.
- **RAGAS (judge)** — faithfulness, answer_relevancy, context_precision,
  context_recall, answer_correctness. Zero-retrieval pairs excluded (see above).
- **System** — p50/p95 latency, token counts, cost estimate.

A run *fails the release gate* if any populated metric misses its per-tier
threshold (see `eval/config.py`); `eval/compare.py` fails on regression > 2 pts.
